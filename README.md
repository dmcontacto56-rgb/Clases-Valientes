# Clases-Valientes · Jeremías

Landing page interactiva (HTML + CSS + JS modular + JSON). Sin dependencias ni build.

```
index.html
css/style.css
js/main.js  audio.js  effects.js  cursor.js
data/content.json
Nuevo-Simbolo-de-la-Iglesia.webp   (ya en el repo)
gota-de-agua.mp3                   (ya en el repo)
```

- Los módulos ES y `fetch` requieren **GitHub Pages** o un servidor local (`python3 -m http.server`); no funcionan con doble clic.
- Foto de portada: sube el archivo y escribe su nombre en `data/content.json` → `meta.coverPhoto`.
- Textos, preguntas, relaciones y recomendaciones semanales se editan en `data/content.json`.
